# SPEC-008: 滑鼠定位器

## 概述

定義「快速找到滑鼠游標」功能：按下全域熱鍵時，在游標所在的螢幕播放約 1.5 秒的視覺特效（聚光燈壓暗 + 螢幕邊框閃爍 + 游標波紋擴散），協助在多螢幕環境中定位游標。

特效層是獨立於時鐘遮罩視窗的第二個原生視窗，不共用 SPEC-001 的視窗實例，兩者疊放策略相反：時鐘遮罩在假全螢幕情境下讓位，特效層則必須覆蓋一切，包含全螢幕播放中的影片與簡報。

本規格與 SPEC-007（滑鼠按鍵綁定 domain）**完全獨立**：不擴充 `MouseAction`、不使用 `CGEventTap`、不需要輔助使用授權。理由見「架構決策」。

## 功能需求

### FR-01: 全域熱鍵觸發

| 項目 | 值 |
|------|-----|
| 優先級 | P0 |
| 來源 | PROP-003 |
| 對應用例 | UC-06 |

**描述**：註冊系統層級全域熱鍵；按下時觸發定位特效，無論當前前景 app 為何。

**約束條件**：

- 熱鍵組合固定為 `Cmd + Option + L`（與 SPEC-005 的設定面板熱鍵 `Cmd + Option + ,` 同前綴）
- 以 `hotkey_manager` 註冊，`scope` 為 `HotKeyScope.system`，沿用 `lib/main.dart` 既有註冊模式
- 註冊失敗時記錄警告並繼續，不影響 app 其餘功能
- app 結束時解除註冊

**驗收標準**：

- [ ] 任何前景 app 下按 `Cmd + Option + L` 皆觸發特效
- [ ] 功能停用時按熱鍵無反應
- [ ] 熱鍵註冊失敗時 app 正常啟動，其餘功能不受影響
- [ ] 觸控板使用者無須任何指向裝置操作即可觸發

### FR-02: 目標螢幕判定與跨螢幕跟隨

| 項目 | 值 |
|------|-----|
| 優先級 | P0 |
| 來源 | PROP-003 |
| 對應用例 | UC-06 |

**描述**：特效播放於游標當下所在的螢幕，與時鐘遮罩的目標螢幕（SPEC-003）無關。

**約束條件**：

**驗收標準**：

- [ ] 游標在第二螢幕時觸發，特效出現於第二螢幕
- [ ] 時鐘顯示於第一螢幕時，於第二螢幕觸發特效不影響時鐘
- [ ] 播放期間將游標移到另一螢幕，特效跟隨

### FR-03: 聚光燈效果

| 項目 | 值 |
|------|-----|
| 優先級 | P0 |
| 來源 | PROP-003 |
| 對應用例 | UC-06 |

**描述**：目標螢幕整體壓暗，游標周圍保留一圈未壓暗的圓形區域，形成手電筒照射效果。

**驗收標準**：

- [ ] 觸發後目標螢幕明顯變暗，游標周圍維持原亮度
- [ ] 播放期間移動游標，亮區跟隨且無可見延遲
- [ ] 亮區邊緣為漸層，非鋸齒硬邊

### FR-04: 螢幕邊框閃爍

|------|-----|

- [ ] 邊框未遮蔽螢幕中央的內容

### FR-06: 設定項目與持久化

| 項目 | 值 |
|------|-----|
| 優先級 | P1 |
| 來源 | PROP-003 |
| 對應用例 | UC-06 |

**描述**：設定面板（SPEC-005）提供三項設定，隨其他設定一併持久化（SPEC-004）。

**約束條件**：

| 設定項 | 型別 | 預設 | 範圍 |
|-------|------|------|------|
| 啟用開關 | bool | true | — |
| 特效時長 | double（秒） | 1.5 | 0.5 ~ 3.0 |
| 主色調 | Color | 系統藍 | 沿用既有色盤元件 |

- `SettingsModel` 的 `schemaVersion` 由 3 升為 **4**
- `fromJson()` 缺欄（v3 及更早資料）→ 補上述預設值，不拋例外
- 停用時解除熱鍵註冊，不僅是略過特效播放
- 設定變更即時生效，無須重啟 app
- **特效時長為含淡出的總時長**：末段淡出在此時長內完成，觸發到視窗釋放的實際耗時等於設定值。淡出不外加於設定值之上——時長下限為 0.5 秒，若淡出另計則下限設定的實際播放時間將顯著偏離使用者所設，且總時長無法作為可驗證的不變量

**驗收標準**：

- [ ] `fromJson(model.toJson()) == model`（含三個新欄位 round-trip）
- [ ] v3 資料解析為預設值，app 不崩潰
- [ ] 停用後熱鍵不再觸發特效
- [ ] 時長與主色調變更即時反映於下次觸發

## 架構決策

### 決策 1：特效層渲染技術

**問題**：特效需出現在任意螢幕，而 SPEC-001 的時鐘遮罩視窗綁定單一螢幕，無法承載。

**結論**：採 Swift `NSWindow` + `CALayer`，不經 Flutter engine。

**排除 Flutter multi-window 的理由**（不依賴 Flutter 版本，故不會隨版本演進失效）：

- 特效視窗需設定 `level = .screenSaver`、`collectionBehavior`、`ignoresMouseEvents` 等 macOS 專屬屬性；無論視窗由誰建立，這些設定都必須以原生程式碼完成
- 聚光燈與波紋需逐幀更新圓心。Core Animation 動畫在 render server 執行，不佔用 Dart isolate；經由 Flutter 繪製則每幀需重建 widget 樹
- 特效層無互動、無狀態、無文字，Flutter 的宣告式 UI、熱重載與跨平台優勢在此情境無從發揮

**版本現況補充**（2026-07-29 查證，此事實會隨版本演進失效，僅供參考）：Flutter 3.38.10 stable 的 `packages/flutter/lib/src/widgets/_window_io.dart` 中 `createDefaultOwner()` 僅有 `Platform.isWindows` 分支，其餘平台回傳 `null`；該檔案標頭載明禁止 production 使用且 patch 版本可能 breaking change。需留意 `binding.dart` 的註解宣稱支援 macOS，與實作不一致，查證時應以原始碼為準。

### 決策 2：觸發機制採全域鍵盤熱鍵

**問題**：專案已有 SPEC-007 的滑鼠按鍵綁定 domain，可擴充 `MouseAction` 新增「定位游標」動作型別，重用其偵測捕捉、清單管理與權限引導。

**結論**：不採用，改以全域鍵盤熱鍵觸發。

**理由**：**觸控板使用者無側鍵可綁**。SPEC-007 的綁定模型以 `buttonNumber` 為鍵，前提是使用者的指向裝置具備可綁定的實體側鍵；觸控板不滿足此前提。鍵盤熱鍵與指向裝置種類無關，是唯一能同時涵蓋滑鼠與觸控板使用者的觸發方式。

**附帶效益**：`hotkey_manager` 不需要輔助使用授權（NFR-03），因此本功能對僅使用觸控板的使用者完全免授權。

**已評估並排除的替代方案**：修飾鍵 + 連點三下（經 `CGEventTap` 攔截並消費，可避免彈出右鍵選單，且觸控板輕點與滑鼠左鍵同為 `leftMouseDown` 故兩者通用）。排除理由：需在左鍵事件流這條最熱路徑上維護三連擊狀態機，判定邏輯出錯會影響所有點擊操作，風險與收益不成比例。

## 介面規格

### 原生層與 Dart 層分工

熱鍵註冊與設定管理在 Dart 側；特效播放全程於 Swift 側閉環。

```dart
// lib/platform/cursor_locator.dart
class CursorLocator {
  /// 在游標所在螢幕播放定位特效。
  Future<void> play({required Duration duration, required Color tint});
}
```

`CursorLocator` 宣告為 concrete class 而非 abstract class：建構子已可注入 `MethodChannel`（見 `cursor_locator_test.dart`），可測試性不依賴額外抽象層；本類別在專案內永遠只有一個實作，開抽象層不增加彈性，僅增加間接層（1.4.0-W1-001.5 J 項，改 SPEC 對齊 code）。

Method channel `screen_clock/cursor_locator` 的 Dart 至原生方向方法：

| 方法 | 參數 | 行為 |
|------|------|------|
| `play` | `{"durationMs": int, "tintArgb": int}` | 於游標所在螢幕播放特效 |

原生層不主動回呼 Dart。播放期間重複觸發時，重置動畫進度而非疊加第二層特效。

## 錯誤處理

| 錯誤場景 | 錯誤碼 | 處理方式 | 使用者提示 |
|---------|--------|---------|-----------|
| 熱鍵註冊失敗 | E_CL_HOTKEY | log warning；功能停用，其餘功能不受影響 | 無 GUI；只 stderr |
| 目標螢幕解析失敗 | E_CL_SCREEN | 退回 `NSScreen.main` | 無 |
| 特效視窗建立失敗 | E_CL_WINDOW | log warning 並略過本次播放 | 無 GUI；只 stderr |

## 設計約束

| 約束 | 說明 | 影響 |
|------|------|------|
| 特效視窗與時鐘遮罩的疊放策略相反 | 時鐘在假全螢幕時讓位，特效層須覆蓋全螢幕內容 | 兩者不可共用視窗屬性設定，須各自維護 |
| 特效視窗必須 `ignoresMouseEvents` | 特效期間使用者仍可繼續操作底下的應用 | 特效層不得含任何互動元件 |
| 常數集中 | channel 名、方法名、動畫預設值依 CLAUDE.md 規範置於 `lib/app_constants.dart` 的 `AppCursorLocator` | 禁硬編碼於 Dart |
| 熱鍵組合本版固定 | `Cmd + Option + L` 不可由使用者變更 | 若與他人環境衝突需改程式碼；開放自訂另立 ticket |
