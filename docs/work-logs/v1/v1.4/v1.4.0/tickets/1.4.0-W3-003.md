依設定 domain 邊界，將 settings_panel.dart（986 行，非票面舊數字 887，PC-162 現況重驗）拆為
lib/widgets/settings/ 下八個檔案，主檔保留組裝骨架與 Save/Cancel 動作列：

- settings_style_section.dart（139 行）：字型大小/描邊寬度/填色/描邊色/時間格式
- settings_screen_section.dart（60 行）：目標螢幕
- settings_system_section.dart（125 行）：開機啟動/生命計時/出生日期
- settings_binding_section.dart（206 行）+ settings_add_binding_flow.dart（222 行）+
  settings_add_binding_flow_fields.dart（149 行）：滑鼠綁定管理與新增流程
  （原 `_AddBindingFlow` 單檔 500 行仍逾 300 閾值，再拆出動作型別選擇/DragScroll
  參數/Hotkey 擷取欄三個子元件至獨立檔案）
- settings_cursor_locator_section.dart（103 行）：滑鼠定位器
- settings_color_picker.dart（128 行）：樣式區與定位器區共用色彩選取元件
  （ticket how.strategy 原文「主檔保留共用元件」，實作改置獨立共用檔以避免
  各 section 檔反向 import 主檔造成耦合，語意等價：共用元件不重複、單一來源）
- settings_panel.dart（149 行）：組裝骨架 + Save/Cancel

純結構搬移：所有 Widget 樹結構、Key、字面值、間距數值原樣保留，僅將
`_addingBinding` 狀態從 `_SettingsPanelState` 移至 `SettingsBindingSection`
自身（拆分後區塊狀態的自然邊界，行為不變——僅該區塊 rebuild 範圍縮小，
不影響任何既有斷言）。新檔案觸發 presence-guard hook（裸 Color/魔術數字/
硬編碼字串），依 hook 要求逐行加註 exempt marker（color-exempt/magic-exempt/
i18n-exempt），標明沿用既有面板字面值、純結構搬移、非本次新增。

- Phase 4 重構評估：本票本身即為 Phase 4 建議的重構執行（W3-002 完成後拆分），
  未發現額外需重構之處。程式碼品質評級 A（domain 邊界清楚、無跨區塊依賴、
  共用元件單一來源）。結論：無需進一步重構。
