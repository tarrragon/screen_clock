### 實作方式

以「壓暗層 + 放射狀漸層遮罩」實現聚光燈，未用 `CAShapeLayer` 挖洞（形狀邊界為硬邊，違反 FR-03「邊緣以漸層過渡」）。

| 元件 | 角色 |
|------|------|
| `dimLayer`（`CALayer`） | 覆蓋整個 `contentLayer`，黑底，`opacity` = `spotlightDimOpacity` |
| `holeMask`（`CAGradientLayer`, `.radial`） | 作為 `dimLayer.mask`：圓心到亮區半徑 alpha 0（該處不壓暗），往外經羽化帶漸變到 alpha 1 |

`CAGradientLayer` 在漸層範圍外沿用最後一個顏色，故羽化帶以外整個螢幕自動拿到 alpha 1，不需另鋪滿。

### 常數（SPEC-008 FR-03）

`spotlightDimOpacity` 0.55（規格上限）／`spotlightBrightRadius` 120／`spotlightEdgeFeather` 40／`spotlightOuterRadius` 為前二者之和／`spotlightBrightStopRatio` 為 120/160 = 0.75。

### 設計決策

1. 壓暗不隨 `progress` 變化：播放末段整體淡出由視窗層級 `fadeAlpha` 負責（FR-06 時長含淡出），renderer 再自行淡出會與其相乘使實際壓暗低於規格值。故 `render` 對 `progress` 無反應屬設計意圖，測試改以「圓心跟隨 `cursorPointInLayer`」覆蓋每幀行為。
2. 圓心取樣：只讀 `frame.cursorPointInLayer`，未呼叫 `NSEvent.mouseLocation`，與 `.4` 波紋共用同一取樣。
3. 正圓非橢圓：漸層半徑分別除以圖層寬與高換算成單位長度，避免非正方形螢幕把亮區拉成橢圓（有專屬測試）。
4. 隱含動畫：所有幾何寫入包在 `CATransaction.setDisableActions(true)`，否則亮區會滑向新位置產生可見延遲。`LayerHostingView` 只處理 hosted layer，不涵蓋本 renderer 自建的 sublayer。
5. 每幀重對齊 bounds：視窗跨螢幕搬移後尺寸改變，壓暗層須重新覆蓋全圖層，否則邊緣露出未壓暗帶。
6. renderer 排序：置於 composite 陣列最前，使後續 `.3` / `.4` 疊在壓暗層之上不被壓暗。
