### 1.4.0-W3-001.1 已提供的基礎（不要重造）

| 提供物 | 用途 |
|--------|------|
| `CursorLocatorEffectRendering` protocol | 你的 renderer 實作此協定：`attach(to:tint:duration:)` / `render(_:)` / `detach()` |
| `CursorLocatorEffectFrame` | 每幀交付的值型別：`progress`（0..1）/ `elapsed` / `duration` / `cursorPointInLayer` / `tint` |
| `CursorLocatorEffectConstants` | 特效數值的單一集中處，你的半徑與透明度加在此 |
| `CursorLocatorCompositeRenderer` | 廣播器；production 目前傳 `renderers: []`，你把自己的 renderer 加進去 |

`cursorPointInLayer` 已是轉換到 `contentLayer` 座標系的點（左下原點），每幀只取樣一次且與 `.4` 波紋共用——**不要自行呼叫 `NSEvent.mouseLocation`**，那會使亮區與波紋圓心在快速移動時偶發偏移。

`contentLayer` 的幾何、`contentsScale`、隱含動畫停用已由 `1.4.0-W3-018` 的 `LayerHostingView` 處理，你不需重複處理。

### 檔案配置（PM 指定，三張特效子票平行進行）

你的實作放**新檔** `macos/Runner/CursorLocatorSpotlightRenderer.swift`。此檔只有你會動。

以下兩處三張子票都會碰，屬預期衝突，PM 整併時手動解，你照常改即可：

1. `CursorLocatorEffectConstants`（`CursorLocatorEffectWindow.swift`）新增你的常數
2. `MainFlutterWindow.swift` 的 `CursorLocatorCompositeRenderer(renderers: [...])` 陣列加入你的 renderer

**不要修改** `CursorLocatorEffectController`、`WindowCursorLocatorSurface`、`LayerHostingView`、其他兩張子票的 renderer 檔。
