### 拆分結果

`lib/app_constants.dart` 的 `AppCursorLocator`（21 個成員混裝五種關切）拆為三個專屬類別：

| 新類別 | 成員 | 對應 domain-map.md bundle | 消費者 |
|--------|------|---------------------------|--------|
| `AppCursorLocatorChannel` | `channelName` / `playMethod` / `durationMsArgKey` / `tintArgbArgKey` | CursorLocator（presentation，傳輸層） | `lib/platform/cursor_locator.dart`、`test/platform/cursor_locator_test.dart`、`test/platform/channel_contract_test.dart`、`test/platform/cursor_locator_hotkey_controller_test.dart` |
| `AppCursorLocatorHotkey` | `physicalKey`（原 `hotkeyPhysicalKey`）/ `modifiers`（原 `hotkeyModifiers`） | CursorLocator（presentation，觸發層，FR-01） | `lib/platform/cursor_locator_hotkey_controller.dart`、`test/platform/cursor_locator_hotkey_controller_test.dart` |
| `AppCursorLocatorSettings` | `defaultEnabled` / `defaultDurationSeconds` / `minDurationSeconds` / `maxDurationSeconds` / `defaultTint` | CursorLocatorSettings（cross-cutting，FR-06） | `lib/models/settings_model.dart`、`lib/widgets/settings/settings_cursor_locator_section.dart`、`test/models/settings_model_test.dart`、`test/widgets/settings_panel_cursor_locator_test.dart`、`test/platform/cursor_locator_hotkey_controller_test.dart`（defaultTint） |

**Channel 獨立成專屬類別的理由（acceptance 條 1）**：channel 契約字面須與 Swift 端逐字一致，由 `channel_contract_test.dart` 讀取 Swift 原始碼文字比對守衛。與 Hotkey 分開（而非合併進同一個「presentation」類別）是因為 Hotkey 不具這條跨語言硬約束、且消費者是完全獨立的檔案（`cursor_locator_hotkey_controller.dart`）——把兩者放進同一類別會讓「必須逐字一致」這條約束擴散到不需要它的成員（`physicalKey` / `modifiers`），弱化類別邊界表達約束的效果。

**Hotkey 成員改名**：搬入 `AppCursorLocatorHotkey` 後移除 `hotkey` 前綴（`hotkeyPhysicalKey` → `physicalKey`、`hotkeyModifiers` → `modifiers`），避免類別名與成員名重複詞（stutter）；建構 `HotKey` 時的成對關係（`HotKey` 建構子非 const）維持不變，兩常數仍在同一類別供註冊處組裝。

### 渲染參數歸屬定案（acceptance 條 2）

10 個渲染參數（`spotlightMaxDimOpacity` / `spotlightRadiusPx` / `borderWidthPx` / `borderFlashCount` / `borderFlashCycleDurationMs` / `rippleStartRadiusPx` / `rippleEndRadiusPx` / `rippleDurationMs` / `rippleCount` / `rippleIntervalMs`）**刪除，不移植至 Swift**。

判定依據：查證 `macos/Runner/CursorLocatorEffectWindow.swift` 內 `CursorLocatorEffectConstants` 列舉，已各自獨立定義同義常數，數值逐一核對一致：

| spotlightRadiusPx | spotlightBrightRadius | 120 = 120 |
| borderWidthPx | borderWidth | 8 = 8 |
| borderFlashCount | flashCycleCount | 3 = 3 |
| borderFlashCycleDurationMs | flashCycleDuration | 200ms = 0.2s |
| rippleStartRadiusPx | rippleStartRadius | 20 = 20 |
| rippleEndRadiusPx | rippleEndRadius | 180 = 180 |
