### 追加驗證項：跨 backingScaleFactor 螢幕搬遷（來源 1.4.0-W3-018）

`1.4.0-W3-018` 為 layer-hosted surface 補上 `contentsScale` 同步，實作於
`LayerHostingView.synchronizeHostedLayer()`，由 `init` / `setFrameSize` /
`viewDidChangeBackingProperties` / `move(toScreenFrame:)` 四處觸發。

其中 `viewDidChangeBackingProperties` 路徑在單一 scale 的開發機上無法真正驗證——
新增的 `testContentsScaleRealignsAfterMove` 斷言的是「搬遷後 layer.contentsScale
與當前 window.backingScaleFactor 一致」，在所有螢幕同 scale 的機器上這條關係恆成立，
測試會綠但沒有區辨力。

**須於實機補驗的判準**（Retina 與非 Retina 混接環境）：

- 特效播放中把游標從 2x 螢幕移到 1x 螢幕（或反向），搬遷後特效繪製不模糊、不出現
  解析度突變的鋸齒
- 搬遷瞬間圖層不停留在舊位置（`1.4.0-W3-018` 已用 `CATransaction.setDisableActions`
  停用隱含動畫並以測試鎖定，實機確認該處理在真實搬遷下有效）

**前置依賴**：兩項判準都需要 `1.4.0-W3-001` 的特效繪製完成才看得見，與本票既有的
M-1~M-8 視覺面判準同批執行。若手邊無混 scale 的雙螢幕環境，於本票記錄「未驗」
而非勾選，不以單螢幕結果代替。

### M-6 判讀修正

初次回報為「波紋與閃光未維持三秒，只有聚焦維持三秒」，經核對 SPEC-008 確認**此為符合規格的行為，非缺陷**：

| 效果 | 規格時長 | 是否持續整個 duration |
|------|---------|---------------------|
| FR-03 聚光燈 | 無獨立時長，圓心持續跟隨游標 | 是，duration 由它界定 |
| FR-04 邊框閃爍 | 閃爍三次，每次週期 200 ms，合計約 600 ms | 否，驗收標準明訂「閃爍三次後消失」 |
| FR-05 游標波紋 | 單圈 500 ms、三圈間隔 150 ms，合計約 800 ms | 否，三圈發完即結束 |

實測次數經確認為邊框三次、波紋三圈，符合 FR-04 / FR-05 的次數約束。M-6 量測對象為聚光燈界定的整體播放窗，實測約 3.0 秒且末段漸淡非瞬滅，未出現 3.2 秒（即淡出未被加在 duration 之後，逾時寬限未污染正常路徑）。

**根因**：`manual-verification-cursor-locator.md` 的 M-6 條目原文僅寫「淡出與總時長：約 3.0 秒」，未指明量測對象為聚光燈，也未載明三效果的時長語意不同，使執行者合理推論為三者皆應持續 3 秒。已於本票同步修正該文件（該檔在本票 `where.files` 範圍內）：M-6 條目標明量測對象、補三效果時長對照表與設計理由，並註明次數才是實機可判讀的判準、時長精度須錄影逐幀檢查。
