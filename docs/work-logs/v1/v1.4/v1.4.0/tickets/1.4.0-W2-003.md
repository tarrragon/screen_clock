新增 test/state/settings_controller_test.dart，涵蓋 domain-map data-management
的 SettingsController 不變式與 SPEC-009 A.4 交易邊界：

- 載入反映持久化值：以 InMemorySettingsService seed 值建立 controller，驗證
  initial/value 等於 seed
- 儲存反映當前狀態：persist() 後 service.load() 等於 controller.value；另補
  update() 去重（等值不觸發 notify）與 resetToStartup() 不寫入持久層兩項行為
- autoLaunch OS 對帳非原子交易（SPEC-009 A.4）：
  - OS 回報成功時 value/持久層皆為要求值
  - OS 回報失敗（_RefusingAutoLaunchService 永遠回傳 false）時 UI 狀態同步回
    OS 真實值並重寫持久層
  - 新增測試專用 _RecordingSettingsService/_RecordingAutoLaunchService 記錄
    呼叫序列，驗證 persist() 先寫持久層（含要求值 true）、OS 對帳不符後才
    第二次寫回（false），佐證「非原子」的實際寫入順序

未修改 lib/ 產品程式碼；test/widgets/settings_panel_binding_test.dart 未變動。
