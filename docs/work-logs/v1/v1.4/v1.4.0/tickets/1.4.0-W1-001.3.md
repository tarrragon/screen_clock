建立 lib/platform/cursor_locator.dart（新檔）：CursorLocator 類別，MethodChannel 可注入（比照 fullscreen_detector.dart 的建構子注入模式）。play() 方法接收設定層參數（double 秒 + Color），在 _durationSecondsToMs / _tintToArgb 兩個具名轉換點換算為傳輸層格式（int 毫秒 / ARGB int）後呼叫原生端 AppCursorLocator.playMethod。PlatformException / MissingPluginException 皆以 developer.log(level: 900) 記錄後吞下，不外洩給呼叫端（骨架階段呼叫端無需處理原生錯誤）。

macos/Runner/MainFlutterWindow.swift 新增 CursorLocatorBridge 類別與 CursorLocatorChannel enum（channel 名 / 方法名 / 參數鍵字面對齊 lib/app_constants.dart 的 AppCursorLocator，因 Swift 無法 import Dart 常數）。awakeFromNib 內以強參考持有 cursorLocatorBridge，收到 play 方法時解析 durationMs / tintArgb 參數並 NSLog 記錄，回傳 nil（不做任何特效播放，刻意保留給 1.4.0-W2-006 / 1.4.0-W3-001）。既有 isOpaque / backgroundColor 透明視窗設定未改動。

驗證：grep 確認兩側四組字面（channelName/playMethod/durationMsArgKey/tintArgbArgKey）皆出現在常數宣告處（AppCursorLocator 與 CursorLocatorChannel），呼叫點無裸字串。

### 兩側字面一致的驗收方式

Swift 端與 Dart 端對 channel 名、方法名、參數鍵必須引用同一組字面。任一側出現硬編碼字串即視為未達成——Swift 無法 import Dart 常數，故 Swift 端須以該平台的常數宣告方式（如 enum 或 struct 常數）承載相同字面，並與 AppCursorLocator 逐項比對。

驗證方式：grep 各字面於 lib/app_constants.dart 與 macos/Runner/ 比對，確認出現位置皆為常數宣告處，無散落於呼叫點的裸字串。

### 本票的範圍邊界（只做骨架）

- Dart 側：建立 lib/platform/cursor_locator.dart，MethodChannel 可注入以利測試（比照 fullscreen_detector.dart 的注入模式）
- Swift 側：MainFlutterWindow.swift 註冊 cursor_locator channel handler，收到 play 僅以 NSLog 記錄
- 不在本票範圍：特效視窗建立與管理（1.4.0-W2-006）、視覺特效繪製（1.4.0-W3-001）、全域熱鍵（1.4.0-W2-005）

收到 play 只記錄不做事是刻意的：本票的產出是可被下游票填入實作的契約骨架，提早實作特效會讓 W2/W3 的介面失去調整空間。

依 .claude/rules/core/observability-rules.md 規則 5，平台互動程式碼的日誌與功能同步寫入，禁止事後補。本票涉及 method channel 呼叫與 handler 註冊，須記錄：channel 註冊完成（info）、play 呼叫入口與參數（debug 或 info）、PlatformException / MissingPluginException 的 code 與 message（warning）。Dart 側使用 dart:developer 的 developer.log 搭配 name 標籤；Swift 側使用 NSLog。
