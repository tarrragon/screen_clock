### 兩側字面一致的驗收方式

Swift 端與 Dart 端對 channel 名、方法名、參數鍵必須引用同一組字面。任一側出現硬編碼字串即視為未達成——Swift 無法 import Dart 常數，故 Swift 端須以該平台的常數宣告方式（如 enum 或 struct 常數）承載相同字面，並與 AppCursorLocator 逐項比對。

驗證方式：grep 各字面於 lib/app_constants.dart 與 macos/Runner/ 比對，確認出現位置皆為常數宣告處，無散落於呼叫點的裸字串。

### 本票的範圍邊界（只做骨架）

### 常數現況補充（1.4.0-W1-001.4 完成後追加）

本票建立時 1.4.0-W1-001.4 尚不存在。.4 已對齊 AppCursorLocator 與 SettingsModel 的 FR-06 預設值，main 上的常數現況如下：

| 常數 | 值 | 用途 |
|------|-----|------|
| channelName | screen_clock/cursor_locator | channel 契約，.4 未改動 |
| playMethod | play | 方法契約，.4 未改動 |
| durationMsArgKey | durationMs | 參數鍵，.4 未改動，語意為毫秒 |
| tintArgbArgKey | tintArgb | 參數鍵，.4 未改動，語意為 ARGB int |
| defaultDurationSeconds | 1.5（double 秒） | FR-06 設定預設值，.4 由 defaultDurationMs 改名改單位 |
| minDurationSeconds / maxDurationSeconds | 0.5 / 3.0（double 秒） | FR-06 範圍，.4 由毫秒 int 改為秒 double |
| defaultTint | Color(0xFF2196F3) | FR-06 主色調，.4 由 Colors.blue 改為普通 Color（MaterialColor 破 round-trip） |

本票須引用的 channel 契約四組（channelName / playMethod / durationMsArgKey / tintArgbArgKey）不受 .4 影響，Swift 端依其對齊即可。

### 秒轉毫秒的換算點（本票的落實位置）

設定層以 double 秒儲存（SettingsModel.cursorLocatorEffectDurationSeconds），傳輸層以 int 毫秒傳遞（durationMsArgKey）。本票建立的 lib/platform/cursor_locator.dart 是兩者交界，換算須在此發生且有明確命名或註解標示——1.4.0-W1-011 實測 E3 確認單位變更無任何機械訊號，換算點若隱含在運算式中，日後修改者無從察覺。

主色調同理：設定層為 Color 物件，傳輸層為 ARGB int（tintArgbArgKey），轉換點須同樣明確。

骨架階段即使尚未真正傳送參數，也應把換算函式或轉換點的位置定出來，讓 1.4.0-W2-006 與 1.4.0-W3-001 有明確的填入位置。
