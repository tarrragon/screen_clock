resolveTarget() 改為回傳 `TargetResolution?`（原為非 optional 的 tuple 型
struct），把 `CursorScreenResolution` 的 index 在此一次兌現成
`CursorScreenSnapshot.Entry`：`.matched`／`.fellBackToMain` 轉為
`TargetResolution(entry:cursorLocation:fellBackToMain:)`，`.unavailable`
轉為 `nil`。`snapshot` 欄位整個移除，呼叫端不再持有 snapshot、不再出現
`snapshot.entries[index]` 索引存取。

呼叫端 `play()` 與 `followCursorScreen()` 的三態 switch 各自收斂為
「guard let target = resolveTarget() else { ... }」+「if target.fellBackToMain { ... }」
的 guard 加一個 if 形態；兩處診斷 log 措辭維持原樣、各自留在呼叫端組裝，
未合併為單一措辭（`play()` 是「螢幕解析退回 main，續行播放」／「無任何
可用螢幕，無法播放」，`followCursorScreen()` 是「播放中退回 main，續行
播放」／「播放中螢幕數歸零，結束播放」）。

`CursorScreenLocator.resolve` 與 `CursorScreenResolution` 的對外契約逐字
未動，僅 private 的 `resolveTarget()` 簽章與内部實作改變。

修改檔案：macos/Runner/CursorLocatorEffectWindow.swift（單一檔案）。
