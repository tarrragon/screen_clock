### 1.4.0-W3-001.1 已提供的基礎（不要重造）

| 提供物 | 用途 |
|--------|------|
| `CursorLocatorEffectRendering` protocol | 你的 renderer 實作此協定：`attach(to:tint:duration:)` / `render(_:)` / `detach()` |
| `CursorLocatorEffectFrame` | 每幀交付的值型別：`progress`（0..1）/ `elapsed` / `duration` / `cursorPointInLayer` / `tint` |
| `CursorLocatorEffectConstants` | 特效數值的單一集中處，你的邊框寬度與週期加在此 |
| `CursorLocatorCompositeRenderer` | 廣播器；production 目前傳 `renderers: []`，你把自己的 renderer 加進去 |

本特效不需游標位置（邊框沿螢幕四周），但需要**絕對時間軸**：`CursorLocatorEffectFrame.elapsed` 是自首幀起算的秒數，直接用它算三次 200 ms 週期，不必從 `progress * duration` 反推。

`contentLayer` 的幾何、`contentsScale`、隱含動畫停用已由 `1.4.0-W3-018` 的 `LayerHostingView` 處理，你不需重複處理。特效視窗 frame 恆等於螢幕 frame，故 `contentLayer.bounds` 即螢幕範圍，邊框貼齊其內緣即可。

### 檔案配置（PM 指定，三張特效子票平行進行）

### SPEC-008 FR-04 的數值約束

- 邊框寬度 8 px，貼齊螢幕 `frame` 內緣
- 閃爍三次，每次淡入淡出週期 200 ms
- 邊框不遮蔽螢幕中央內容，僅佔用四周邊緣
- 顏色取自使用者設定的主色調（`CursorLocatorEffectFrame.tint`，非硬編碼）

驗收標準（SPEC 原文）：目標螢幕四周出現邊框並閃爍三次後消失；非目標螢幕無任何邊框；邊框未遮蔽螢幕中央的內容。

「非目標螢幕無邊框」由控制器的單一 surface 設計保證（特效視窗只建在目標螢幕），你不需另做螢幕判定；但你的 renderer 不得在 layer 之外畫任何東西。

總時長由設定驅動，而閃爍週期固定 200 ms x 3 = 600 ms。若 duration 短於 600 ms 需決定行為（截斷或壓縮），請在 Solution 記錄你的取捨與理由——SPEC 未規定此邊界。
