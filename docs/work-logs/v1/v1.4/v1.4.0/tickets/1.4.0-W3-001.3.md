### 設計取捨

**1. 邊框以單一 `CALayer.borderWidth` 描繪，非四條矩形子圖層**

`borderWidth` 由 Core Animation 往 `bounds` 內緣描繪且不填滿內部（`backgroundColor` 保持 nil），故「寬 8 px、貼齊 frame 內緣、僅佔四周邊緣不遮蔽中央」三項約束由圖層屬性本身保證，不依賴四條矩形的座標推導與角落接合正確性。

**2. duration 短於 600 ms 採「截斷」而非「壓縮」（SPEC 未規定，本票決定）**

`flashAlpha(elapsed:)` 只吃 `elapsed`，週期固定 `flashCycleDuration`（200 ms），與 `duration` 完全無關；播放在 `duration` 結束時由控制器 `detach`，故短 duration 時自然閃不足三次。

理由：SPEC-008 FR-04 對「每次淡入淡出週期 200 ms」是明文約束，對「三次」的呈現完整性則由總時長間接決定。壓縮週期會使明文數值隨使用者設定漂移（duration=0.3 時週期變 100 ms），等同違反明文約束以滿足未明文的完整性；截斷則保留可辨識的閃爍節奏，僅次數變少。此外壓縮需在 renderer 內引入 `duration` 依賴，使時間曲線與總時長耦合，重置換 duration 時曲線意義會改變。

**3. `elapsed` 而非 `progress * duration`**

依 ticket 指示與 `CursorLocatorEffectFrame.elapsed` 的設計意圖：`progress` 已對 `duration` 正規化，反推會引入除零與夾限的邊界處理，且與取捨 2 的固定週期語意相衝。

**4. attach 時 `opacity = 0` 起始**

attach 與首幀之間可能間隔一次螢幕更新，以 opacity 1 起始會閃出一格全亮邊框（elapsed=0 的曲線值為 0，兩者不一致）。

**5. `borderLayer` 為 `private(set)` 內部可見**

`CALayer` 的實際呈現無法在單元測試環境取樣，故以圖層屬性（frame / borderWidth / borderColor / opacity / backgroundColor）作為驗收的可觀測面。寫入仍限本型別。
