#### 二、project.pbxproj 是所有新增 Swift 檔的共同競爭點（本 ticket 的關鍵約束）

1.4.0-W1-028 實證：此專案非 filesystem-synchronized group，**新增 Swift 檔需手動補 `project.pbxproj` 的 PBXBuildFile / FileReference / Group / SourcesBuildPhase 四類條目**，漏補的症狀會偽裝成「測試沒跑到」而非「檔案沒編譯」。

因此凡會新增 `macos/Runner/` 下檔案的票，都會寫入 `project.pbxproj`：

| ticket | 新增檔案 |
|--------|---------|
| 1.4.0-W1-021.1 | `InputBindingErrorMapping.swift`（1 個） |
| 1.4.0-W2-015 | 拆分產物（多個） |
| 1.4.0-W3-011 | 拆分產物（多個） |

`project.pbxproj` 是 Xcode 專案檔，格式為巢狀屬性清單且含大量 UUID，**merge 衝突極難人工解析**。這使「同時派發兩張會新增 Swift 檔的票」的風險遠高於一般同檔衝突。此約束須納入 DAG——即使兩票在 `.swift` 層面正交，只要都新增檔案就不宜並行。
