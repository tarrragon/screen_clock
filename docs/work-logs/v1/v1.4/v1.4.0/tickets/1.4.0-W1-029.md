於 `.gitignore` 的 Claude framework 區塊（52 行，緊接既有 `__pycache__/` 之後）加入 `*.egg-info/` 一行。

選用 `*.egg-info/` 而非 `.claude/skills/*/*.egg-info/` 的理由：egg-info 是 Python 建置產物的通用形態，不限於 `.claude/skills/` 下；限定路徑的規則會在其他位置出現 Python 套件時失效。既有 `__pycache__/` 同樣採無路徑限定的形態，兩者一致。

未執行 `git rm --cached`：`git ls-files | grep -c egg-info` 於改動前後皆為 0，無歷史誤入版控的檔案需要清除。
