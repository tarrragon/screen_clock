### Task Reference
- 1.4.0-W3-018 what: 修正 layer-hosted surface 的幾何與 contentsScale 同步缺口

### Rationale Chain
- 1.4.0-W3-018 why: 1.4.0-W3-008 將 WindowCursorLocatorSurface 的 hostView 從 layer-backed（wantsLayer=true 由 AppKit 自建 layer）改為 layer-hosted（自行指派 contentLayer）。此改動消除了孤兒圖層，但同時換走 AppKit 對 hosted layer 的兩項自動同步：(1) resize 時 layer.frame 不再跟隨 view bounds；(2) contentsScale 不再對齊 window.backingScaleFactor。move(toScreenFrame:) 呼叫 window.setFrame，跨不同解析度螢幕跟隨時 contentLayer.frame 停留在初始尺寸；Retina 螢幕上 contentsScale 停在 1.0 使繪製模糊。兩者皆無錯誤無日誌，與 W3-008 要消滅的形態同型
