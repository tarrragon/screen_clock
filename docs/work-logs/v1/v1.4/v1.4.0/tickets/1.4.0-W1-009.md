### 三方比對產出格式

Solution 章節須含三張對照表：

| 表 | 欄位 |
|----|------|
| FR 覆蓋 | FR 編號 / 描述摘要 / 對應 ticket / 狀態（已覆蓋 / 缺口） |
| UC 場景覆蓋 | 場景名稱 / 類型（主成功 / 替代 / 例外） / 對應 ticket / 狀態 |
| Proposal checklist 覆蓋 | checklist 項目 / 對應 ticket / 狀態 |

缺口項須建對應 ticket 並回填 spawned_tickets（quality-baseline 規則 5）。缺口數量多時可設計為一組有依賴關係的實作票，於 Solution 附派發順序建議。
