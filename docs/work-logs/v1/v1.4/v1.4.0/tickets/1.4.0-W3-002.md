### 職責邊界（避免與並行票重疊）

- **值域 0.5-3.0 的執行期夾制屬 1.4.0-W2-010**（model 層 `fromJson`）。本票的 Slider `min` / `max` 引用 `AppCursorLocator.minDurationSeconds` / `maxDurationSeconds` 常數即可，**不在 UI 層重複實作夾制邏輯**——兩處各寫一份夾制會在日後範圍調整時漂移。
- **熱鍵註冊 / 解除屬 1.4.0-W2-005**。本票只需讓啟用開關寫回 `SettingsController`；「停用即解除註冊」由 W2-005 的監聽機制負責（UC-06 06c）。本票不呼叫 `hotKeyManager`。

### 實作摘要

新增 `_buildCursorLocatorSection`（含子方法 `_buildCursorLocatorEnabled` /
`_buildCursorLocatorDuration`）於 `lib/widgets/settings_panel.dart`，插入於既有
滑鼠綁定區與「儲存/取消」按鈕列之間，形態對齊 `_buildBindingSection`：

- 啟用開關：Switch 綁定 `current.cursorLocatorEnabled`，onChanged 僅
  `controller.update(...)` 寫回，不呼叫 hotKeyManager（熱鍵註冊/解除留 W2-005 監聽鏈）。
- 特效時長：Slider `min`/`max` 直接引用 `AppCursorLocator.minDurationSeconds` /
  `maxDurationSeconds`，不在 UI 層重複實作值域夾制（夾制屬 W2-010 `fromJson`）。
  `divisions: 25` 由 (3.0-0.5)/0.1 推導，對齊既有滑桿 0.1 精度慣例。
- 主色調：直接重用既有 `_buildColorPicker`（未新增色盤元件），符合 SPEC 明文要求。
- 三者皆走既有 Save/Cancel 暫存模型（非即時持久化），點擊「儲存」觸發
  `SettingsController.persist()` 一併寫入。

`lib/app_constants.dart` 新增 4 個 `AppText` 常數
（`cursorLocatorSectionTitle` / `cursorLocatorEnabledLabel` /
`cursorLocatorDurationLabel` / `cursorLocatorColorLabel`）。

### Presence-detection-hook 摩擦（已提報 SR-1）

新增/既有 AppText 字面觸發 `presence-detection-hook`（user-facing 字串 /
魔術數字兩類），因該 hook 的通用 `_DART` profile skip_patterns 未收錄本專案
檔名 `app_constants.dart`（該檔即 CLAUDE.md §6 指定的專案唯一文案 sink，
角色等同框架已收錄的 `ui_constants.dart` 等檔）。逐行以 `// i18n-exempt` /
`// magic-exempt` 標記通過（含說明性註解），systemic 修法已建 SR-1 追蹤，
非本票範圍。

  格式化差異，非本票邏輯變更；已確認 `flutter analyze` 0 issues、全套件測試不受影響。
- **結論**：無需重構；技術債僅 SR-1（presence-detection-hook skip_patterns
