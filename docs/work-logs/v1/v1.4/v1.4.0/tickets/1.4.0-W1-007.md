### A 區與 B 區的分界（可攜性邊界原則）

| 區 | 性質 | 本專案對應內容 |
|----|------|--------------|
| A 區（邏輯契約，DB-agnostic） | 換一種儲存後端仍成立的約定 | 各 schema 版本的欄位語意、型別、值域；不變式（如 schemaVersion 單調遞增、欄位一旦加入不再移除）；預設值來源；migration 保證（舊版讀入不丟資料） |
| B 區（實作綁定，DB-specific） | 綁定當前儲存實作的細節 | JSON 檔實際路徑、序列化格式細節、讀寫觸發時機、檔案損毀或不存在時的降級行為 |

判準：若把 JSON 檔換成 SQLite 後仍需遵守，屬 A 區；只在 JSON 實作下成立，屬 B 區。
