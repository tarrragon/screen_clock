新增 test/platform/display_detector_test.dart，涵蓋 domain-map platform 的
DisplayDetector 兩條不變式：

1. 螢幕清單至少包含主螢幕：listDisplays 正常/失敗兩路徑、resolveTargetDisplay
   於 null/有效索引/越界/負數索引/空清單/主螢幕偵測亦失敗等情境的 fallback 行為。
2. 熱插拔事件觸發重新偵測：startWatching 訂閱後，screen event 觸發重新查詢
   displays；目標仍在時不動作、目標消失（含清單縮短為空）時觸發 onTargetLost；
   stopWatching 後不再回呼；重複呼叫 startWatching 改用最新 watchedIndex；
   事件處理中查詢失敗不外洩例外。

平台通道以 _FakeScreenRetrieverPlatform（extends ScreenRetrieverPlatform）取代
screen_retriever 的 MethodChannel 實作，透過 ScreenRetrieverPlatform.instance
注入，不依賴真實多螢幕環境。因此需在 pubspec.yaml dev_dependencies 新增
screen_retriever_platform_interface（screen_retriever 的傳遞依賴，flutter
analyze 的 depend_on_referenced_packages 規則要求直接依賴），純 Dart 套件，
不含原生 pod，不影響 macOS pod 安裝狀態。

未修改 lib/ 產品程式碼。
