### 問題根因

`1.4.0-W3-008` 為消除孤兒圖層，把 `WindowCursorLocatorSurface.contentLayer` 從

```swift
var contentLayer: CALayer { hostView.layer ?? CALayer() }
```

改為 `init` 自建並持有的 non-optional stored property，指派順序為
`hostView.layer = contentLayer` 先於 `hostView.wantsLayer = true`
（`CursorLocatorEffectWindow.swift:490` 宣告、`:502-505` 指派）。

該順序使 `hostView` 成為 **layer-hosted** view（而非原本的 layer-backed）。
兩者在 AppKit 的責任分界不同：

| 模式 | layer 由誰建立 | resize 時 layer.frame | contentsScale |
|------|--------------|---------------------|---------------|
| layer-backed（原） | AppKit（`wantsLayer = true` 觸發） | AppKit 自動同步 view bounds | AppKit 自動對齊 `backingScaleFactor` |
| layer-hosted（現） | 呼叫端自建並指派 | **不同步**，由呼叫端負責 | **不設定**，預設 1.0 |

修正換走了孤兒圖層的可能性，同時換走了上表右兩欄的自動行為。

### 影響範圍

兩處後果，皆在 `1.4.0-W3-001` 開始繪製後才顯現：

1. **跨螢幕搬遷後幾何錯位** — `move(toScreenFrame:)`（`:525-527`）只呼叫
   `window.setFrame`。`hostView` 作為 `contentView` 會被 AppKit resize，但 hosted
   `contentLayer.frame` 停留在 `init` 時的 `hostView.bounds`。UC-06 替代場景 06a
   跨螢幕跟隨時，若兩螢幕解析度不同，繪製區域被裁切或偏移。

2. **Retina 上繪製模糊** — `contentsScale` 停在 1.0，2x 螢幕上實際渲染解析度減半。
   跨螢幕搬遷至不同 `backingScaleFactor` 的螢幕時同樣不更新。

兩者共通症狀：**無錯誤、無日誌、僅畫面異常**。與 W3-008 要消滅的形態同型。

### 測試覆蓋現況

零覆蓋。`macos/RunnerTests/Support/CursorLocatorTestDoubles.swift:155` 的
`contentLayer` 是獨立 `CALayer()` test double，與真實 `NSWindow` 的 resize 行為無關。
現有 SurfaceContract 群組驗的是 protocol 契約，不觸及 `WindowCursorLocatorSurface`

### 修改內容

`macos/Runner/CursorLocatorEffectWindow.swift`：

1. 新增 `LayerHostingView`（private NSView 子類），集中 hosted layer 的同步責任：
   - `synchronizeHostedLayer()`：`layer.frame = bounds` + `layer.contentsScale = window.backingScaleFactor`，整段包在 `CATransaction.setDisableActions(true)` 內。
   - `override setFrameSize(_:)` → resize 時同步幾何。
   - `override viewDidChangeBackingProperties()` → 視窗搬到不同 backingScaleFactor 螢幕時重新對齊 scale。
2. `WindowCursorLocatorSurface.hostView` 型別由 `NSView` 改為 `LayerHostingView`。
3. `init` 於 `window.setFrame` 後呼叫 `synchronizeHostedLayer()`（掛上視窗後才知道 backingScaleFactor，init 建 layer 時只設得了 frame）。
4. `move(toScreenFrame:)` 於 `setFrame` 後呼叫 `synchronizeHostedLayer()`（同尺寸跨螢幕搬遷不觸發 setFrameSize，且 backing 變更通知送達時機由 AppKit 決定；顯式呼叫使搬遷回傳時幾何與 scale 皆已就位）。

### 實測修正 ticket 前提：兩項假設只有一項成立

RED 階段五條新測試中，只有 contentsScale 兩條紅：

| ticket 假設 | 實測 |
|-----------|------|
| resize 後 hosted `layer.frame` 不跟隨 view bounds | 不成立。macOS 26 下 AppKit 仍由 view 幾何推導 hosted layer 的 bounds/position，未改碼前該斷言即綠 |
| `contentsScale` 停在 1.0 | 成立。本機 Retina（backingScaleFactor 2.0）下 layer 停在 1.0，init 與 move 後皆紅 |

幾何同步仍保留在 `setFrameSize` 內：AppKit 對 hosted layer 的幾何推導未見於文件，屬實作細節，不宜當契約倚賴。顯式同步使正確性與 AppKit 版本無關，成本是一次 `frame` 指派。對應測試改以回歸鎖定角色存在。

### 測試策略：沿用既有 app-hosted 群組，未新增權限風險

`CLAUDE.md` §7 記載的無人值守權限彈窗風險，本票查證後不成立：`RunnerTests` 早已設 `TEST_HOST`／`BUNDLE_LOADER`（`project.pbxproj:514-521`），且 `CursorLocatorSurfaceContractTests`（W2-006 群組 F）本就建立真實 `NSWindow` 並在 `scripts/run-tests.sh` 下無人值守通過。本票五條新測試併入該既有群組，不新增測試 target、不註冊 CGEventTap，故不引入新的彈窗阻塞面。因此不需採「抽為純函式以便單元測試」的退路——真實 `NSWindow` resize 後的 layer 幾何可直接觀察。

### acceptance 第 4 條：反向掃描結果

掃描對象為「layer-backed → layer-hosted 這次轉換讓 AppKit 停止做的事」，逐項對照本專案是否用得到：

| 候選（換走的行為） | 本專案是否用到 | 處置 |
|-----------------|------------|------|
| `layer.frame` 隨 view bounds 同步 | 是（跨螢幕搬遷） | 已顯式同步（實測 AppKit 仍做，但不倚賴） |
| `contentsScale` 對齊 backingScaleFactor | 是（Retina 繪製） | 已修，init + move + viewDidChangeBackingProperties 三處觸發 |
| 隱含動畫停用（第三處，本次新發現） | 是 | 已修。layer-backed 時 AppKit 以 `layer.delegate = view` 讓 `defaultAction(forKey:)` 回傳停用 action；hosted layer 的 delegate 為 nil，改 frame 會啟動 0.25 秒隱含動畫，搬遷期間圖層仍畫在舊位置。同步已包 `CATransaction.setDisableActions(true)`，並由 `testGeometrySyncDoesNotStartImplicitAnimation` 鎖定 |
| `layer.delegate` 的 `draw(_:in:)` 回調 | 否 | 不處置。`macos/Runner/*.swift` 全樹無 `draw(_:)`／`drawRect` 使用；`contentLayer` 是交給 W3-001 renderer 直接繪製的目標（W2-006 §協定設計），非經 NSView 繪製路徑 |
| `needsDisplay` 傳遞至 layer | 否 | 不處置。僅在 delegate 繪製路徑下有意義，同上不適用 |
| `layerContentsRedrawPolicy` 預設值 | 否 | 不處置。該屬性僅作用於 AppKit 自建（layer-backed）的圖層，對 hosted layer 無效 |
| 動態 backingScaleFactor 變更通知 | 是 | 已含在第 2 項，`viewDidChangeBackingProperties` 覆寫 |

結論：第三處為隱含動畫停用，已於本票一併修正並納入測試；其餘候選經逐項確認後屬本專案用不到的行為，不需補償。
