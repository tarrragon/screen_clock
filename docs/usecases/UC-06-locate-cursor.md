# UC-06: 快速定位滑鼠游標

## 基本資訊

| 項目 | 值 |
|------|-----|
| 用例 ID | UC-06 |
| 用例名稱 | 快速定位滑鼠游標 |
| 主要行為者 | 多螢幕桌面使用者（使用滑鼠或觸控板） |
| 利益關係人 | 使用者：省去掃視各螢幕尋找游標的時間；底下的應用：操作不被中斷 |
| 前置條件 | app 執行中；滑鼠定位器設定為啟用 |
| 成功保證 | 游標所在螢幕播放定位特效；特效結束後畫面無殘留；底下的應用可持續操作 |

## 主要成功場景

1. **觸發**
   - 使用者按下 `Cmd + Option + L`
   - 前景為任何 app 皆可觸發；不需要操作滑鼠或觸控板

2. **判定目標螢幕**
   - 原生層讀取 `NSEvent.mouseLocation`
   - 於 `NSScreen.screens` 中找出 `frame` 涵蓋該座標的螢幕

3. **建立特效視窗**
   - 於目標螢幕建立透明、置頂、不接收滑鼠事件的原生視窗
   - 視窗層級高於全螢幕應用

4. **播放特效**
   - 聚光燈遮罩淡入，螢幕壓暗，游標周圍保留明亮圓形區域
   - 螢幕四周邊框以使用者設定的主色調閃爍三次
   - 游標位置向外擴散三圈波紋
   - 播放期間圓心與波紋中心跟隨游標移動

5. **結束**
   - 依使用者設定的特效時長（預設 1.5 秒）後整層淡出
   - 特效視窗釋放

6. **使用者找到游標**
   - 使用者繼續原本的操作

## 替代場景

### 06a: 特效播放期間游標移至另一螢幕

**觸發條件**：使用者在特效播放期間將游標移動到別的螢幕

1. 原生層偵測到游標所在螢幕改變
2. 特效視窗移動至新螢幕並繼續播放
3. 回到主要成功場景步驟 5

### 06b: 播放期間重複觸發

**觸發條件**：特效尚未結束時使用者再次按下熱鍵

1. 重置動畫進度，從頭播放
2. 不疊加第二層特效視窗
3. 回到主要成功場景步驟 4

### 06c: 功能已停用

**觸發條件**：使用者於設定面板停用滑鼠定位器

1. 熱鍵註冊已解除
2. 按下 `Cmd + Option + L` 不產生任何反應，該組合鍵回歸系統預設行為

### 06d: 於全螢幕應用之上觸發

**觸發條件**：使用者正在全螢幕播放影片或簡報時觸發

1. 特效視窗以高於全螢幕內容的層級建立
2. 特效正常播放，覆蓋於全螢幕內容之上
3. 回到主要成功場景步驟 5

> 此行為與時鐘遮罩相反。時鐘遮罩在假全螢幕情境下讓位，特效層則必須可見，因為使用者是在該情境下主動請求協助。

### 06e: 未取得輔助使用授權

**觸發條件**：使用者未授權輔助使用（例如僅使用觸控板、無滑鼠按鍵綁定需求）

1. 熱鍵註冊與特效播放皆不受影響，功能正常運作
2. 回到主要成功場景

> `hotkey_manager` 以 Carbon `RegisterEventHotKey` 註冊，不受輔助使用權限管轄（SPEC-008 NFR-03）。

## 例外場景

### EX-06-01: 熱鍵註冊失敗

| 項目 | 值 |
|------|-----|
| 觸發條件 | 熱鍵組合已被其他 app 佔用，或系統拒絕註冊 |
| 錯誤碼 | E_CL_HOTKEY |
| 處理方式 | log warning 至 stderr；定位器停用；app 其餘功能不受影響 |
| 使用者提示 | 無 GUI 提示 |
| 恢復策略 | 使用者關閉佔用該組合鍵的 app 後，重啟 screen_clock |

### EX-06-02: 目標螢幕解析失敗

| 項目 | 值 |
|------|-----|
| 觸發條件 | 游標座標不落在任何 `NSScreen.frame` 內（螢幕排列間隙等邊界狀況） |
| 錯誤碼 | E_CL_SCREEN |
| 處理方式 | 退回 `NSScreen.main` 播放特效 |
| 使用者提示 | 無 |
| 恢復策略 | 不需要；特效仍會播放，僅螢幕可能非預期 |

### EX-06-03: 特效視窗建立失敗

| 項目 | 值 |
|------|-----|
| 觸發條件 | 系統資源不足導致 `NSWindow` 建立失敗 |
| 錯誤碼 | E_CL_WINDOW |
| 處理方式 | log warning 至 stderr；略過本次播放 |
| 使用者提示 | 無 GUI 提示 |
| 恢復策略 | 使用者可再次觸發 |

## 已知限制

| 限制 | 使用者可觀察到的現象 |
|------|-------------------|
| 觸發需按鍵盤 | 手正在滑鼠或觸控板上時，須移到鍵盤才能觸發 |
| 熱鍵組合本版固定 | 無法於設定面板變更 `Cmd + Option + L` |
| 無法變更系統游標本身的外觀 | 游標本身不變色，變化來自疊加於其上的特效層 |
